# liminal 宿主适配层契约

本文定义 liminal 与宿主物理后端（UE5 Chaos / Godot / Bevy）适配壳之间的稳定边界。
任何适配层实现（如 CirrovaEngine）必须遵守本文；修改本文视为破坏性变更。

## 1. 职责边界

| 职责 | 归属 |
| --- | --- |
| 拓扑编排、连接校验、图编译 | liminal |
| 信号同步（拓扑序拷贝） | liminal |
| 1D 动力流求解（转速连通组与速度级约束） | liminal |
| 挂载位姿链推导（静止位形） | liminal |
| 轮胎模型（力解与约束参数两种输出形态）、悬挂法向力与防倾杆模型（纯函数） | liminal |
| 6DoF 刚体积分、碰撞求解 | 宿主物理 |
| 接触检测（射线/扫掠）与接触坐标系构造 | 适配层 |
| 侧偏角计算（需宿主速度场） | 适配层 |
| 力/冲量的施加 | 适配层 |
| 轮胎摩擦约束的构建（约束形态） | 适配层 |
| 轮胎反作用力矩回注 1D 域 | 适配层（经 `liminal_vehicle_write_torque`） |

## 2. 坐标系与单位

- liminal 拓扑内部一律使用 SI：米、千克、秒、牛顿、牛·米、弧度。
- liminal 载具坐标系：**X = 右（车轮滚动轴），Y = 上（悬挂/转向轴），Z = 前**。
- 适配层负责到宿主坐标系的基变换。UE（X 前，Y 右，Z 上）的变换四元数为
  `(0.5, 0.5, 0.5, 0.5)`（循环置换 X→Y→Z→X），长度再乘 100（米 → 厘米），
  力乘 100（N → kg·cm/s²）。
- 挂载约定：空间端口可声明挂载位姿（`Frame`，节点本地系）。一条空间连接在
  静止位形下令两端挂载位姿重合，因此 `T_childInParent = T_parentMount ∘ T_childMount⁻¹`。
- 关节量（旋转轴、平移轴、行程）定义在**子节点本地坐标系**。
- 四元数分量顺序统一为 (x, y, z, w)。

## 3. 节拍契约

- 适配层注册宿主物理引擎的求解器子步回调（UE5：`Chaos::TSimCallbackObject`，
  `Presimulate` 选项），载具模拟在物理线程每求解器步执行一次；宿主在一次外部步内
  做多次演化子步时，这些子步共享同一份输入快照。
- 回调时间步为求解器子步长。外力形态下，适配层在回调内部仍做 ≤ 2.5 ms 的内部子步
  （上限 32 子步/求解器步），作为宿主未启用物理子步时的稳定化安全网；约束形态不执行
  内部子步。
- 外力形态的每个内部子步执行「轮胎力求值 → 车轮反作用力矩注入 → `liminal_vehicle_step`
  → 读回轮速」；约束形态在 Presimulate 写入接触、悬挂目标与约束输入，在 PostSolve
  消费同一物理步的冲量 → 回注轮端力矩 → `liminal_vehicle_step` → 产出快照。
- 外力形态的合力在每个求解器步内对内部子步取平均，直接写入底盘粒子的力/力矩累加器，
  由宿主求解器在本子步内消费。
- 子步化的目的：轮胎力与轮速为显式耦合，帧级步长下回路增益超过数值稳定阈值
  （Jolt 以求解器内隐式约束消除该问题）；子步化把增益压回稳定区。
- 接触检测与悬挂解每求解器子步一次；候选对象由适配层在游戏线程按车轮扫掠盒
  收集，窄相射线在物理线程经宿主的物理对象查询接口执行。游戏线程不得在物理线程
  调用 `UWorld` 碰撞查询。
- 接触点速度包含车身角速度贡献与地面刚体（静态、运动学或动态）在接触点的平动与
  转动贡献；静态地面速度为零。
- 防倾杆在两侧车轮同时接地时按压缩差求成对附加法向力，并计入轮胎摩擦椭圆的总法向载荷；
  任一车轮离地时不产生作用力。悬挂与防倾杆的支撑力沿悬挂轴作用于轮心；轮胎法向
  载荷只作为摩擦椭圆输入，不重复施加。
- 悬挂在支持约束的宿主上映射为原生悬挂约束（UE5：`FPhysicsInterface::CreateSuspension`，
  由 `Chaos::FPBDSuspensionConstraints` 求解）；射线接触仍提供接触坐标系与法向载荷
  输入，约束创建失败时逐轮回退为弹簧力施加。
- 悬挂约束可用时，适配层应读回约束的位置修正 `NetPushOut` 还原真实支撑力（含弹簧、
  阻尼与硬限位），而不是仅用 `k·compression` 或射线估计；`NetPushOut` 为位置求解
  累积的 kg·cm 修正量，等效法向力 = 投影 / dt²。宿主未暴露该结果时退回模型估计。
- Chaos 原生悬挂在低速时默认把地面法线替换为世界上方（防滑机制）。适配层应显式
  关闭该机制（UE5：`p.Chaos.Suspension.SlopeThreshold=1`，Cirrova 对应
  `Cirrova.SuspensionSlopeAssist=0`），并以真实悬挂轴作为约束法向，否则斜坡上的
  轮胎摩擦会被掩盖。
- 轮胎耦合有两种形态，适配层按宿主能力选择：
  - **约束形态**：轮胎以两条标量约束进入宿主求解器的速度迭代。纵向目标为轮面线速度
    与地面速度之和（可先经纵向松弛滤波），侧向目标为零相对速度；两轴共享载荷敏感
    摩擦椭圆界，纵向与侧向各有独立附着系数。低速时按合成滑移速度在动摩擦界与静摩擦
    界之间过渡。地面物理材质的动/静摩擦与轮胎附着按几何平均合并。纵向有效质量取
    `1/m_eff + R²/J_eff`，把轮端自由度消元进约束，冲量在底盘与轮端之间分配。制动扭矩
    作为第二条作用于轮端的角冲量约束行（`ω → 0`，界 `T_b·dt`）进入同一迭代，与轮胎行
    按 PGS 交替求解；锁止由两行的容量竞争涌现，无需预判。净角冲量（轮胎反作用 + 制动）
    在同一物理步的 PostSolve 以力矩回注。该形态不要求内部子步。
  - **外力形态**：轮胎模型输出力解与车轮反作用力矩，适配层以内部子步把显式回路的
    增益压回稳定区。

## 4. 每帧行为序列（适配层）

游戏线程（每帧一次，物理步进前）：

1. 写入驾驶信号（油门/转向/挡位/制动/手刹）到异步输入，供物理线程消费；
   liminal 端口写入在物理线程执行。
   信号语义：油门与制动 ∈ [0, 1]；挡位 0 = 空挡，k = 第 k 个传动比；
   转向 = 目标转角（弧度，绕转向轴；liminal 车辆坐标系 X=右，Y=上，Z=前，故正值为右转；
   驾驶输入的正值为左转，适配层负责取反）。适配层按需在物理线程逐轮直写
   转向与制动信号（阿克曼转角、手刹、ABS），舱内信号端口可不再连接。
2. 为每个载具编组底盘物理代理，并在游戏线程按车轮扫掠盒收集宽相候选对象；
   窄相射线在物理线程对候选对象执行。

物理线程（每个求解器子步一次）：

3. 对每个车轮：从静止位姿（`pose_in_root`）得到悬挂上挂点，沿空间域导出的悬挂轴
   向下投射（射线、球体扫掠或轮宽多射线包络，适配层按宿主能力选择），长度按轴倾角
   补偿车轮半径。
   命中后轮心 = 接触点 + 接触法线·半径，当前弹簧长度 = 轮心在悬挂轴上的投影，
   钳制到 `[min_length, max_length]`；未命中 `current = max_length` 且不产生轮胎与悬挂力。
   接触法线与底盘上向量夹角超过 80° 的垂直墙面应被忽略，避免车轮把墙面当作支撑面。
   地面物理材质的动/静摩擦系数随接触解一并读出，供轮胎模型合并。
4. 压缩量 `x = rest_length - current`，压缩速度 `ẋ = (x - x_prev) / dt`；
   外力回退路径可钳制到 ±2 m/s（等效减振器泄压阀）；原生悬挂约束路径保留真实值。
   首次求解跳过速度计算，避免出生位形阶跃。
   悬挂法向力 `F_N = liminal_suspension_force(k, c, x, ẋ)`（SI，只推不拉）。
   防倾杆对 `F_arb = liminal_anti_roll_force(k_arb, x_a, x_b)`（A 侧增加、B 侧减少），
   仅在两侧均接地时生效；轮胎法向载荷取支撑力在接触法线上的投影，即
   `max((F_N + F_arb)·(axis·n), 0)`。
5. 构造接触坐标系：法线 `n` 取命中法线；纵向 `l` 为轮前向在接触平面上的投影
   （前向 = 底盘前向绕该轮转向轴旋转该轮转向角）；侧向 `a = n × l`。接触点速度（含车身
   角速度与地面刚体速度贡献）在此处缓存。轮心取接触点沿法线偏移车轮半径，弹簧
   长度取轮心在悬挂轴上的投影。
6. 若启用原生悬挂约束：以轮心为目标点、真实悬挂轴为法向、接地状态为启用标志，
   更新约束目标；约束在求解器位置迭代内施加弹簧/阻尼力。约束轴取空间域导出的
   悬挂轴；Chaos 的 `max_length` 取 `rest_length`（弹簧自由长度），行程下限取
   `min_length`。射线侧的 `max_length` 是允许的满行程，两者语义不同。

内部子步（每个内部子步一次）：

7. `slip_angle = atan2(v_a, max(|v_l|, 1.0))`。
8. 轮胎冲量解
   `F = liminal_tire_impulse_forces(&model, ω, v_l, R, J_eff, slip_angle, v_a, F_N, dt)`：
   `model` 含附着系数、侧向刚度、载荷敏感与滚动阻力；`J_eff` 为
   `liminal_vehicle_effective_inertia` 给出的轮端等效惯量，应优先于单轮惯量；
   纵向由本步内对齐轮面线速度与地面速度所需冲量折算（等效刚度 J_eff/R²），
   侧向由侧偏刚度与低速速度阻尼共同给出，合力按载荷敏感后的摩擦椭圆裁剪，并叠加
   滚动阻力。返回值同时携带车轮反作用力矩。
9. 阻力侧零过冲：纵向阻力不得超过 `m_chassis·|v_l| / (dt·接地轮数)`。
10. 回注车轮反作用力矩：`liminal_vehicle_write_torque(wheel_shaft_port, forces.wheel_torque)`
    （仅含摩擦力矩，滚动阻力不产生车轮反作用）。适配层的阻力侧钳制若修改了纵向力，
    须按 `-ΔF_long·R` 同步修正力矩。
11. `liminal_vehicle_step(sub_dt)`，读回轮速并刷新
    `liminal_vehicle_effective_inertia`，供下一内部子步使用。

求解器子步收尾：

12. 支撑力沿悬挂轴作用于轮心：未启用原生悬挂约束时为 `axis·(F_N + F_arb)`，
    启用时为 `axis·F_arb`（悬挂力由约束承担）。轮胎合力
    `l·F_long + a·F_lat` 作用于接触点。支撑力为整步常量，轮胎力取内部子步平均值。
    法向载荷取支撑力在接触法线上的投影，仅用于摩擦椭圆，不单独施加。启用原生约束时，
    法向载荷应由 `NetPushOut` 还原的支撑力投影给出，而不是 `k·compression`。

约束形态仍在上述第 1 至 6 步完成接触、悬挂目标与载荷，之后替换第 7 至 12 步：

7. 每个求解器步写入一次约束输入：
   `liminal_tire_constraint(&model, v_l, α, v_a, F_N)` 返回纵向/侧向动摩擦界、静摩擦界、
   侧向力与滚动阻力。`FLiminalTireModel` 含纵向附着系数、侧向附着系数、侧向刚度、
   载荷敏感、参考载荷、滚动阻力与静摩擦倍率；适配层应先把地面材质的动/静摩擦与轮胎
   系数按几何平均合并，再换算到宿主单位。
   纵向冲量界取 `longitudinal_limit·dt`，侧向冲量界取 `lateral_limit·dt`；两轴共同受
   椭圆 `(Fx/FxMax)² + (Fy/FyMax)² ≤ 1` 约束。低速时可用合成滑移速度在动/静界之间
   插值。适配层可对轮面速度与侧偏角分别施加一阶松弛过滤（轮胎松弛长度），模拟胎体瞬态。
   目标速度由轮速与地面速度给出。
8. 宿主求解器在速度迭代内求解两轴冲量；纵向有效质量取底盘接触点逆质量与
   `R²/J_eff` 之和，轮端 `J_eff` 由 `liminal_vehicle_effective_inertia` 查询；制动扭矩
   作为作用于轮端的第二条角冲量约束行参与同一迭代，锁止由容量竞争涌现。椭圆界内的
   坐标块迭代顺序为纵向→侧向，每轴可用半轴长度由另一轴当前冲量决定。适配层可在
   宿主位置迭代内叠加位置级静摩擦修正（仅静摩擦区间、沿接触平面、有界），并在动态
   工况对侧向冲量做跳步 warm start。
9. 求解后的冲量在同一物理步的 PostSolve 换算为力与车轮反作用力矩，经
   `liminal_vehicle_write_torque` 回注一维域，随后推进 `liminal_vehicle_step`；
   轮速与约束目标之间不再存在跨帧滞后。求解器承担制动的轮，转向节制动信号应写 0
   （权威门控）；离地或载荷为零的轮仍由转向节摩擦约束承担制动。
10. 滚动阻力作为外力施加于接触点，不产生车轮反作用；防倾杆仍按成对附加力施加。
11. 约束形态不执行内部子步；约束求解使用本步开始时的轮速，纵向有效质量已包含
    `R²/J_eff`，轮端反作用与制动角冲量在同一物理步内回注，轮速不存在跨帧滞后。

## 5. 数据访问契约

- 空间装配：`liminal_vehicle_spatial_link(_count)` 导出运动学树，每条含关节描述、
  控制端口、`rest_pose`（子相对父）与 `pose_in_root`（子相对底盘）。
- 端口索引（节点端口表顺序）：
  - CockpitInput：0 油门，1 转向，2 挡位，3 制动；
  - Engine：0 油门，1 轴；Gearbox：0 挡位，1 输入，2 输出；Axle：0 输入，k+1 输出；
  - Suspension：0 上挂点，1 下挂点；SteeringKnuckle：0 上，1 下，2 转向，3 制动，4 轴；
  - Wheel：0 轴，1 挂点；SignalSplitter：0 输入，k+1 输出。
- 外部扭矩注入（`liminal_vehicle_write_torque`）：覆盖式写入，单步消费后清零；
  仅对处于连通组件内的端口生效。
- 轮端等效惯量：`liminal_vehicle_effective_inertia(vehicle, port, out_inertia)`
  返回端口所在转速连通组折算到该端口的等效惯量（kg·m²）；显式轮胎力耦合应使用
  该值，锁止轴与低挡位工况下它包含传动链的折算惯量。
- C ABI 版本：`liminal_abi_version()` 返回 `LiminalAbiVersion`；宿主应在初始化时
  校验，头文件与静态库版本不一致时拒绝运行。当前版本为 3（P1.3 摩擦椭圆、静摩擦界
  与地面材质字段）；版本 2 的 `friction_force` 字段已重命名为纵向/侧向椭圆界。
- 差速器：`liminal_vehicle_add_differential(output_count, max_torque, inertia)`，
  端口布局与 `Axle` 相同（0 输入，k+1 输出）。求解器施加开式差速约束
  `ω_in = mean(ω_out)` 并等扭矩分配输出端；限滑为输出端之间的库仑摩擦约束，
  传递扭矩不超过 `max_torque`，`max_torque = 0` 即纯开式。
- 防倾杆：`liminal_anti_roll_force(stiffness, compression_a, compression_b)` 返回
  附加在 A 侧的法向力，B 侧取反；适配层负责成对配对与离地门控。
- 发动机：`liminal_vehicle_add_engine` 为线性衰减且关闭怠速/制动；
  `liminal_vehicle_add_engine_with_params` 可传入全油门扭矩曲线（归一化角速度/扭矩比例）、
  怠速角速度/扭矩上限与满转速发动机制动扭矩（N·m）。
- 轮胎：`liminal_tire_impulse_forces(model, ω, v_l, R, J_eff, slip_angle, v_a, F_N, dt)`
  使用 `FLiminalTireModel`（纵向附着系数、侧向附着系数、侧向刚度、载荷敏感度、
  参考载荷、滚动阻力、静摩擦倍率），返回 `wheel_torque`（仅摩擦力矩）。
- 约束形态轮胎：`liminal_tire_constraint(model, v_l, slip_angle, v_a, F_N)` 返回
  `longitudinal_limit` / `lateral_limit`（载荷敏感后的动摩擦椭圆半轴）、
  `static_longitudinal_limit` / `static_lateral_limit`（静摩擦半轴）、
  `lateral_force`（含低速速度阻尼的侧向力）与 `rolling_force`（逆向地面速度的滚动
  阻力）。全部单位为 N；适配层负责换算到宿主的力与冲量单位。
- 原生悬挂约束映射（UE5）：约束本地偏移 = 自由长度下的轮心
  （`mount − axis·rest_length`，相对底盘原点）；轴 = 空间域导出的悬挂轴；
  `min_length` = −(rest_length − 行程下限)（压缩行程，负值）；
  `max_length` = 0（自由长度；liminal 弹簧在自由长度以上无伸展力）；
  `spring_stiffness` = `(k·curve_scale(x) + bump_stiffness(x>start)) / N`；
  `spring_damping` = `c_dir·dt / N`，`c_dir` 按压缩速度方向取压缩或回弹阻尼；
  （N 为宿主位置求解迭代数；Chaos 在每次位置迭代中完整施加弹簧，官方 ChaosVehicles 固定取 N=4）；
  `spring_preload` 置 0（UE 5.8 求解器未将预载计入弹簧）；适配层沿悬挂轴外部施加预载并计入
  `F_N`；目标点 = 当前轮心。
  约束力沿真实悬挂轴施加，大小按 `axis·normal` 缩放且只推不拉；求解长度为相对
  静止轮心的有符号位移（压缩为负），适配层按 `rest_length + length` 还原绝对
  弹簧长度，目标超出自由长度时求解器将其钳制到 `max_length`。
  适配层应以 `NetPushOut`（kg·cm）还原支撑力：`F_N = (NetPushOut + HardStopNetPushOut)·n / dt²`，
  再换算为 N；该值包含弹簧、阻尼、刚度曲线与硬限位，且反映刚体多约束耦合后的真实支撑力。
- 扩展悬挂模型（适配层）：分向压缩/回弹阻尼、以压缩量为自变量的刚度倍率曲线、渐进限位
  与预载。库的 `liminal_suspension_force` 仍为基础线性模型；外力回退形态由适配层按同一
  扩展模型求值。
- 所有 FFI 调用须保证同一时刻只有一个线程访问句柄（句柄非线程安全）。
- 宿主回调模式下，句柄在游戏线程构建，随异步输入发布给物理线程后仅由物理线程访问；
  注销时的销毁按宿主生命周期规则执行（求解器命令队列或世界销毁路径），全程无并发访问。

## 6. 已知限制

- **差速器**：开式差速约束 + 摩擦限滑。开式部分在求解器内等扭矩分配；
  限滑为输出端之间的库仑摩擦约束（扭矩容量 `max_torque`）。差速器惯量计入输入端。
- **阻尼泄压钳制**：外力回退路径的压缩速度被钳制到 ±2 m/s，属于显式耦合的稳定化措施
  （真实减振器靠泄压阀实现类似行为）；原生悬挂约束路径保留真实压缩速度（仅 20 m/s
  数值防护上限），遥测不失真。
- **质量适配**：默认参数面向约 1 吨级底盘。底盘质量过轻（如默认立方体）会使
  悬挂刚度与阻尼相对质量过大，表现为弹飞与翻滚；适配层应在初始化时校验质量
  并在日志中警告，悬挂参数按质量缩放。
- **子步上限**：每个求解器步内最多 32 个内部子步，帧率低于约 15 fps 且宿主未启用物理子步时，
  内部子步长会超过 2.5 ms，轮胎回路的数值稳定性随之退化。
- **离合器**：摩擦约束在扭矩上限 `engagement·max_torque·dt` 内锁止，超出则滑摩。
  离合器惯量计入输入端。
- **原生悬挂约束**：Chaos 的弹簧在每次位置迭代中完整施加，设定值需按迭代数折算；
  适配层按 `k/N`、`c·dt/N` 写入，N 取求解器当前位置迭代数。迭代数或步长变化时
  有效刚度/阻尼会漂移。约束只推不拉；目标超出自由长度时无作用力。启用约束形态时，
  适配层应读回 `NetPushOut` 还原真实法向载荷；宿主未暴露该结果时退回模型估计。
  Chaos 的低速斜坡防滑应关闭（`p.Chaos.Suspension.SlopeThreshold=1`），并以真实悬挂轴
  作为约束法向，否则轮胎摩擦在斜坡上会被悬挂法线掩盖。
- **原生悬挂的地面体**：`SetSuspensionTarget` 只接受单粒子物理代理（单刚体）作为地面体；
  高度场/复杂静态网格等非单粒子代理不会建立约束，弹簧不产生作用力。适配层应按
  命中代理类型逐轮禁用原生约束并改用射线弹簧力，轮胎约束保持不变；Cirrova 提供
  `bForceSuspensionFallback` 开关与 T18 无头场景覆盖该回退路径。
- **约束形态的轮端耦合**：车轮角速度仍由一维域积分；纵向约束在有效质量中消元
  `R²/J_eff`，冲量与轮端反作用在同一物理步回注。P1.4 起制动扭矩作为作用于轮端的
  第二条角冲量约束行进入同一求解器迭代（界 `T_b·dt`），与轮胎行按 PGS 交替求解，
  锁止由容量竞争涌现；净角冲量（轮胎反作用 + 制动）在同一物理步回注。制动器扭矩
  仍由一维域定义（转向节 `max_brake_torque`），适配层承担逐轮信号路由与权威门控。
- **扩展悬挂模型**：分向阻尼、刚度倍率曲线、渐进限位与预载由适配层实现；UE 5.8 不消费
  `SpringPreload`，预载为沿悬挂轴的外部力；曲线是刚度倍率而非力曲线，渐进限位是线性
  附加刚度。回退路径使用同一模型，Cirrova 以 T18 无头场景覆盖该路径。
- **约束形态的静态摩擦**：轮胎约束是速度级 PGS；适配层可在宿主位置迭代内叠加
  位置级静摩擦修正（沿接触平面、仅静摩擦区间、≤ 0.5 cm/步），Cirrova P1.5 已实现，
  T4/T5 准静态漂移降至厘米级。速度级残差仍存在，但不再持续累积。侧向 warm start
  仅在动态工况启用（静止时与位置修正叠加会放大漂移）。
- **物理状态重建**：原生悬挂约束在载具注册时绑定底盘物理对象；运行时重建底盘
  物理状态（切换碰撞、重设模拟）会使约束指向旧粒子，需要重新注册载具。
- **轮胎模型**为摩擦椭圆限制下的纵向冲量解与侧向刚度/低速速度阻尼模型，含载荷敏感、
  纵/侧向独立附着与静摩擦倍率；约束形态输出椭圆四轴界、侧向力与滚动阻力，外力形态
  输出力解。库模型本身无状态，瞬态松弛由适配层对轮面速度与侧偏角做一阶过滤。
- **接触探针**：Chaos `ShapeSweep` 的几何分派不支持 `FCylinder`；圆柱包络以轮宽多射线
  实现，取沿悬挂轴最先命中的接触。真正的圆柱形状扫掠需宿主暴露更底层查询接口。
- **发动机**：默认（`add_engine`）为线性衰减且关闭怠速/发动机制动；高级参数需使用
  `add_engine_with_params`。怠速为比例控制（无积分项），稳态误差由控制带宽决定。
  适配层可关闭内置线性发动机制动并按转速曲线注入反向扭矩（Cirrova `bUseEngineBrakingCurve`）。
- **燃料与能量**：FluidFuel 域的端口与载荷已定义，但单元尚未实现；liminal 当前没有
  单元逐物理步状态钩子，完整燃料/热模型需新增逐 step 阶段与 ABI 版本升级。
- 空间域存在环时编译失败（`CompileError::SpatialCycle`）；空间连接未连接到
  底盘根节点时编译失败（`CompileError::SpatialDisconnected`），不再静默忽略。

## 7. 构建接入

UE 侧（CirrovaEngine）链接本 crate 的 `staticlib` 产物：

```
cd ThirdParty/liminal
cargo build --release
# 产物：target/release/liminal[.lib|.a]
```

构建 UE 工程前须先执行上述命令；`Cirrova.Build.cs` 已配置库路径。
宿主初始化时须校验 `liminal_abi_version() == LiminalAbiVersion`；头文件中的
`static_assert` 会在布局漂移时直接编译失败。
