# liminal 宿主适配层契约

本文定义 liminal 与宿主物理后端（UE5 Chaos / Godot / Bevy）适配壳之间的稳定边界。
任何适配层实现（如 CirrovaEngine）必须遵守本文；修改本文视为破坏性变更。

## 1. 职责边界

| 职责 | 归属 |
| --- | --- |
| 拓扑编排、连接校验、图编译 | liminal |
| 信号同步（拓扑序拷贝） | liminal |
| 1D 动力流求解（发动机/变速箱/轴/轮的角速度积分） | liminal |
| 挂载位姿链推导（静止位形） | liminal |
| 轮胎力模型、悬挂法向力模型（纯函数） | liminal |
| 6DoF 刚体积分、碰撞求解 | 宿主物理 |
| 接触检测（射线/扫掠）与接触坐标系构造 | 适配层 |
| 滑移率/侧偏角计算（需宿主速度场） | 适配层 |
| 力/冲量的施加 | 适配层 |
| 轮胎反作用力矩回注 1D 域 | 适配层（经 `liminal_vehicle_write_torque`） |

## 2. 坐标系与单位

- liminal 拓扑内部一律使用 SI：米、千克、秒、牛顿、牛·米、弧度。
- liminal 载具坐标系：**X = 右（车轮滚动轴），Y = 上（悬挂/转向轴），Z = 前**。
- 适配层负责到宿主坐标系的基变换。UE（X 前，Y 右，Z 上）的变换四元数为
  `(0.5, 0.5, 0.5, 0.5)`（循环置换 X→Y→Z→X），长度再乘 100（米 → 厘米），
  力乘 100（N → kg·cm/s²）。
- 挂载约定：空间端口可声明挂载位姿（`Frame`，节点本地系）。一条空间连接在
  静止位形下令两端挂载位姿重合，因此 `T_childInParent = T_parentMount ∘ T_childMount⁻¹`。
- 关节量（旋转轴、平移轴、行程）定义在**子节点本地坐标系**。
- 四元数分量顺序统一为 (x, y, z, w)。

## 3. 节拍契约

- 适配层在帧内做内部子步：子步长 ≤ 2.5 ms（上限 32 子步/帧）。
- 每个子步执行「轮胎力求值 → 反作用力矩注入 → `liminal_vehicle_step` → 读回轮速」。
- 帧末对子步合力取平均，一次施加给宿主刚体（阶段 A：宿主力接口）。
- 子步化的目的：轮胎力与轮速为显式耦合，帧级步长下回路增益超过数值稳定阈值
  （Jolt 以求解器内隐式约束消除该问题）；子步化把增益压回稳定区。
- 接触检测与悬挂解每帧一次（帧内几何不变），接触点速度缓存后供各子步复用。
- 阶段 B 起轮胎力升级为冲量边界格式（见第 6 节）。

## 4. 每帧行为序列（适配层）

帧级（每帧一次）：

1. 写入驾驶信号（油门/转向/挡位/制动）到驾驶舱端口。
   信号语义：油门与制动 ∈ [0, 1]；挡位 0 = 空挡，k = 第 k 个传动比；
   转向 = 目标转角（弧度，绕悬挂上轴，正值为左转）。
2. 对每个车轮：从静止位姿（`pose_in_root`）得到悬挂上挂点，沿悬挂轴向下投射，
   长度 = `max_length + wheel_radius`。命中则计算当前弹簧长度
   `current = hit_distance - radius`，钳制到 `[min_length, max_length]`；
   未命中 `current = max_length` 且不产生轮胎与悬挂力。
3. 压缩量 `x = rest_length - current`，压缩速度 `ẋ = (x - x_prev) / dt` 并钳制到
   ±2 m/s（等效减振器泄压阀）；首次求解跳过速度计算，避免出生位形阶跃。
   悬挂法向力 `F_N = liminal_suspension_force(k, c, x, ẋ)`（SI，只推不拉）。
4. 构造接触坐标系：法线 `n` 取命中法线；纵向 `l` 为轮前向在接触平面上的投影
   （前向 = 底盘前向绕悬挂轴旋转转向角）；侧向 `a = n × l`。接触点速度（含车身
   角速度贡献）在此处缓存。

子步级（每子步一次）：

5. `slip_angle = atan2(v_a, max(|v_l|, 1.0))`。
6. 冲量模式轮胎解 `F = liminal_tire_impulse_forces(μ, Cy, ω, v_l, R, J_w, slip_angle, F_N, dt)`：
   纵向由本步内对齐轮面线速度与地面速度所需冲量折算（等效刚度 J_w/R²），
   侧向按侧偏刚度，合力按摩擦圆 μ·F_N 裁剪。
7. 阻力侧零过冲：纵向阻力不得超过 `m_chassis·|v_l| / (dt·接地轮数)`。
8. 回注反作用力矩：`liminal_vehicle_write_torque(wheel_shaft_port, -F_long·R)`。
9. `liminal_vehicle_step(sub_dt)` 并读回轮速。

帧级收尾：

10. 子步合力取平均，施加 `n·F_N + l·F_long + a·F_lat` 于接触点
    （阶段 A/B：宿主力接口）。

## 5. 数据访问契约

- 空间装配：`liminal_vehicle_spatial_link(_count)` 导出运动学树，每条含关节描述、
  控制端口、`rest_pose`（子相对父）与 `pose_in_root`（子相对底盘）。
- 端口索引（节点端口表顺序）：
  - CockpitInput：0 油门，1 转向，2 挡位，3 制动；
  - Engine：0 油门，1 轴；Gearbox：0 挡位，1 输入，2 输出；Axle：0 输入，k+1 输出；
  - Suspension：0 上挂点，1 下挂点；SteeringKnuckle：0 上，1 下，2 转向，3 制动，4 轴；
  - Wheel：0 轴，1 挂点；SignalSplitter：0 输入，k+1 输出。
- 外部扭矩注入（`liminal_vehicle_write_torque`）：覆盖式写入，单步消费后清零；
  仅对处于连通组件内的端口生效。
- 差速器：`liminal_vehicle_add_differential(output_count, coupling, max_torque, inertia)`，
  端口布局与 `Axle` 相同（0 输入，k+1 输出）。
- 轮胎冲量解：`liminal_tire_impulse_forces` 为阶段 B 主路径；
  `liminal_tire_forces`（刚度 + 滑移率）保留供力模式参考。
- 所有 FFI 调用须在同一线程（句柄非线程安全）。

## 6. 升级路线（施加语义）

- **阶段 A（当前）**：力模式。适配层把轮胎/悬挂力作为外力施加，
  1D 域经反作用力矩闭环。等价于 ChaosVehicles 的延迟力模式。
- **阶段 B（已实现）**：冲量语义。纵向由“本步内对齐轮面与地面速度”的冲量折算，
  侧向仍为刚度模型，合力按摩擦圆裁剪；适配层附加阻力侧零过冲钳制。
  消除了低速/静止时轮胎力跨零震荡，替代 Chaos 的 K=0.4 补丁。
  施加载体仍为宿主力接口（每子步合力帧末取平均）。
- **阶段 C**：原生约束模式。适配层把 `SpatialJointDesc` + 控制端口映射为宿主
  原生约束（Jolt `VehicleConstraint` 同款原语），liminal 只提供约束方程参数。

## 7. 已知限制（调试期可接受）

- **差速器**：已提供粘性差速器单元（`Differential`）：输出端转速差按
  `coupling·Δω` 传递扭矩并受扭矩容量限制，是开式差速器的近似。`coupling` 越大
  越接近锁止，越小越接近开式；真正的等扭矩开式差速需要 1D 求解器支持约束方程。
  耦合系数受稳定性约束：`coupling·dt·Σ(1/J) < 2`。`Axle` 仍为刚性锁止轮轴。
- **静止蠕行**：阻性扭矩钳制允许“制动恰好抵消驱动并停转”，但停转后驱动扭矩
  仍会使转速以 `τ_drive·dt/J` 的幅度逐帧累积。接触中的车轮由地面反作用主导，
  实际不可见；离地空转的轴仍会缓慢爬升。
- **阻尼泄压钳制**：压缩速度被钳制到 ±2 m/s，属于调试期稳定化措施而非物理
  模型（真实减振器靠泄压阀实现类似行为）。高速坠地时着陆冲击弱于真实车辆。
- **质量适配**：默认参数面向约 1 吨级底盘。底盘质量过轻（如默认立方体）会使
  悬挂刚度与阻尼相对质量过大，表现为弹飞与翻滚；适配层应在初始化时校验质量
  并在日志中警告，悬挂参数按质量缩放。
- **子步上限**：内部子步最多 32 步/帧，帧率低于约 15 fps 时子步长会超过
  2.5 ms，轮胎回路的数值稳定性随之退化。
- **离合器锁死判据**为转速差阈值，未做扭矩容量校验；`lock_threshold` 须大于
  单步扭矩积分 `τ·dt/J`，否则锁死/滑摩抖动。
- **动态地面**：滑移计算假设地面静止（静态碰撞体）。动态刚体上的接触速度未计入。
- **轮胎模型**为线性刚度 + 摩擦圆，无载荷敏感 μ、无滚动阻力。
- 发动机无扭矩曲线与怠速，扭矩随转速线性衰减；无 engine braking。
- 空间域存在环时静默取树（BFS），未像信号域那样报错。

## 8. 构建接入

UE 侧（CirrovaEngine）链接本 crate 的 `staticlib` 产物：

```
cd ThirdParty/liminal
cargo build --release
# 产物：target/release/liminal[.lib|.a]
```

构建 UE 工程前须先执行上述命令；`CirrovaEngine.Build.cs` 已配置库路径。
