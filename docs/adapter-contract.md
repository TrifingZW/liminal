# liminal 宿主适配层契约

本文定义 liminal 与宿主物理后端（UE5 Chaos / Godot / Bevy）适配壳之间的稳定边界。
任何适配层实现（如 CirrovaEngine）必须遵守本文；修改本文视为破坏性变更。

## 1. 职责边界

| 职责 | 归属 |
| --- | --- |
| 拓扑编排、连接校验、图编译 | liminal |
| 信号同步（拓扑序拷贝） | liminal |
| 1D 动力流求解（转速连通组与速度级约束） | liminal |
| 挂载位姿链推导（静止位形） | liminal |
| 轮胎力模型、悬挂法向力与防倾杆模型（纯函数） | liminal |
| 6DoF 刚体积分、碰撞求解 | 宿主物理 |
| 接触检测（射线/扫掠）与接触坐标系构造 | 适配层 |
| 侧偏角计算（需宿主速度场） | 适配层 |
| 力/冲量的施加 | 适配层 |
| 轮胎反作用力矩回注 1D 域 | 适配层（经 `liminal_vehicle_write_torque`） |

## 2. 坐标系与单位

- liminal 拓扑内部一律使用 SI：米、千克、秒、牛顿、牛·米、弧度。
- liminal 载具坐标系：**X = 右（车轮滚动轴），Y = 上（悬挂/转向轴），Z = 前**。
- 适配层负责到宿主坐标系的基变换。UE（X 前，Y 右，Z 上）的变换四元数为
  `(0.5, 0.5, 0.5, 0.5)`（循环置换 X→Y→Z→X），长度再乘 100（米 → 厘米），
  力乘 100（N → kg·cm/s²）。
- 挂载约定：空间端口可声明挂载位姿（`Frame`，节点本地系）。一条空间连接在
  静止位形下令两端挂载位姿重合，因此 `T_childInParent = T_parentMount ∘ T_childMount⁻¹`。
- 关节量（旋转轴、平移轴、行程）定义在**子节点本地坐标系**。
- 四元数分量顺序统一为 (x, y, z, w)。

## 3. 节拍契约

- 适配层注册宿主物理引擎的求解器子步回调（UE5：`Chaos::TSimCallbackObject`，
  `Presimulate` 选项），载具模拟在物理线程、每求解器子步执行一次。
- 回调时间步为求解器子步长。适配层在回调内部仍做 ≤ 2.5 ms 的内部子步
  （上限 32 子步/求解器步），作为宿主未启用物理子步时的稳定化安全网。
- 每个内部子步执行「轮胎力求值 → 车轮反作用力矩注入 → `liminal_vehicle_step` → 读回轮速」。
- 合力在每个求解器步内对内部子步取平均，直接写入底盘粒子的力/力矩累加器，
  由宿主求解器在本子步内消费。
- 子步化的目的：轮胎力与轮速为显式耦合，帧级步长下回路增益超过数值稳定阈值
  （Jolt 以求解器内隐式约束消除该问题）；子步化把增益压回稳定区。
- 接触检测与悬挂解每求解器子步一次；候选对象经宽相盒查询收集，窄相射线在
  物理线程经宿主的物理对象查询接口执行。
- 接触点速度包含车身角速度贡献与地面刚体（静态、运动学或动态）在接触点的平动与
  转动贡献；静态地面速度为零。
- 防倾杆在两侧车轮同时接地时按压缩差求成对附加法向力，并计入轮胎摩擦圆的总法向载荷；
  任一车轮离地时不产生作用力。
- 悬挂在支持约束的宿主上映射为原生悬挂约束（UE5：`FPhysicsInterface::CreateSuspension`，
  由 `Chaos::FPBDSuspensionConstraints` 求解）；射线接触仍提供接触坐标系与轮胎法向
  载荷估计，约束创建失败时逐轮回退为弹簧力施加。

## 4. 每帧行为序列（适配层）

游戏线程（每帧一次，物理步进前）：

1. 写入驾驶信号（油门/转向/挡位/制动）到异步输入，供物理线程消费；
   liminal 端口写入在物理线程执行。
   信号语义：油门与制动 ∈ [0, 1]；挡位 0 = 空挡，k = 第 k 个传动比；
   转向 = 目标转角（弧度，绕悬挂上轴，正值为左转）。
2. 为每个载具编组底盘物理代理、碰撞通道与射线查询参数。

物理线程（每个求解器子步一次）：

3. 对每个车轮：从静止位姿（`pose_in_root`）得到悬挂上挂点，沿悬挂轴向下投射，
   长度 = `max_length + wheel_radius`。命中则计算当前弹簧长度
   `current = hit_distance - radius`，钳制到 `[min_length, max_length]`；
   未命中 `current = max_length` 且不产生轮胎与悬挂力。
4. 压缩量 `x = rest_length - current`，压缩速度 `ẋ = (x - x_prev) / dt` 并钳制到
   ±2 m/s（等效减振器泄压阀）；首次求解跳过速度计算，避免出生位形阶跃。
   悬挂法向力 `F_N = liminal_suspension_force(k, c, x, ẋ)`（SI，只推不拉）。
   防倾杆对 `F_arb = liminal_anti_roll_force(k_arb, x_a, x_b)`（A 侧增加、B 侧减少），
   仅在两侧均接地时生效；轮胎法向载荷取 `max(F_N + F_arb, 0)`。
5. 构造接触坐标系：法线 `n` 取命中法线；纵向 `l` 为轮前向在接触平面上的投影
   （前向 = 底盘前向绕悬挂轴旋转转向角）；侧向 `a = n × l`。接触点速度（含车身
   角速度与地面刚体速度贡献）在此处缓存。
6. 若启用原生悬挂约束：以轮心为目标点（接触点沿底盘上方向偏移半径）、接触法线为
   法向、接地状态为启用标志，更新约束目标；约束在求解器位置迭代内施加弹簧/阻尼力。

内部子步（每个内部子步一次）：

7. `slip_angle = atan2(v_a, max(|v_l|, 1.0))`。
8. 轮胎冲量解 `F = liminal_tire_impulse_forces(&model, ω, v_l, R, J_w, slip_angle, F_N, dt)`：
   `model` 含附着系数、侧向刚度、载荷敏感与滚动阻力；纵向由本步内对齐轮面线速度
   与地面速度所需冲量折算（等效刚度 J_w/R²），侧向按侧偏刚度，合力按载荷敏感后的
   摩擦圆裁剪，并叠加滚动阻力。返回值同时携带车轮反作用力矩。
9. 阻力侧零过冲：纵向阻力不得超过 `m_chassis·|v_l| / (dt·接地轮数)`。
10. 回注车轮反作用力矩：`liminal_vehicle_write_torque(wheel_shaft_port, forces.wheel_torque)`
    （仅含摩擦力矩，滚动阻力不产生车轮反作用）。适配层的阻力侧钳制若修改了纵向力，
    须按 `-ΔF_long·R` 同步修正力矩。
11. `liminal_vehicle_step(sub_dt)` 并读回轮速。

求解器子步收尾：

12. 内部子步合力取平均，以底盘粒子为作用点施加 `n·(F_N + F_arb) + l·F_long + a·F_lat`
    （逐求解器子步生效）；启用原生悬挂约束时 `n·F_N` 由约束承担，仅施加轮胎合力与
    防倾杆力。

## 5. 数据访问契约

- 空间装配：`liminal_vehicle_spatial_link(_count)` 导出运动学树，每条含关节描述、
  控制端口、`rest_pose`（子相对父）与 `pose_in_root`（子相对底盘）。
- 端口索引（节点端口表顺序）：
  - CockpitInput：0 油门，1 转向，2 挡位，3 制动；
  - Engine：0 油门，1 轴；Gearbox：0 挡位，1 输入，2 输出；Axle：0 输入，k+1 输出；
  - Suspension：0 上挂点，1 下挂点；SteeringKnuckle：0 上，1 下，2 转向，3 制动，4 轴；
  - Wheel：0 轴，1 挂点；SignalSplitter：0 输入，k+1 输出。
- 外部扭矩注入（`liminal_vehicle_write_torque`）：覆盖式写入，单步消费后清零；
  仅对处于连通组件内的端口生效。
- 差速器：`liminal_vehicle_add_differential(output_count, max_torque, inertia)`，
  端口布局与 `Axle` 相同（0 输入，k+1 输出）。求解器施加开式差速约束
  `ω_in = mean(ω_out)` 并等扭矩分配输出端；限滑为输出端之间的库仑摩擦约束，
  传递扭矩不超过 `max_torque`，`max_torque = 0` 即纯开式。
- 防倾杆：`liminal_anti_roll_force(stiffness, compression_a, compression_b)` 返回
  附加在 A 侧的法向力，B 侧取反；适配层负责成对配对与离地门控。
- 发动机：`liminal_vehicle_add_engine` 为线性衰减且关闭怠速/制动；
  `liminal_vehicle_add_engine_with_params` 可传入全油门扭矩曲线（归一化角速度/扭矩比例）、
  怠速角速度/扭矩上限与满转速发动机制动扭矩（N·m）。
- 轮胎：`liminal_tire_impulse_forces(model, ...)` 使用 `FLiminalTireModel`
  （附着系数、侧向刚度、载荷敏感度、参考载荷、滚动阻力），返回 `wheel_torque`（仅摩擦力矩）。
- 原生悬挂约束映射（UE5）：轴 = 底盘上方向；`min_length` = 行程下限；
  `max_length` = 自由长度；`spring_stiffness` = k（N/m 数值）；
  `spring_damping` = c·dt（求解器步长）；目标点 = 轮心。
- 所有 FFI 调用须保证同一时刻只有一个线程访问句柄（句柄非线程安全）。
- 宿主回调模式下，句柄在游戏线程构建，随异步输入发布给物理线程后仅由物理线程访问；
  注销时的销毁按宿主生命周期规则执行（求解器命令队列或世界销毁路径），全程无并发访问。

## 6. 已知限制

- **差速器**：开式差速约束 + 摩擦限滑。开式部分在求解器内等扭矩分配；
  限滑为输出端之间的库仑摩擦约束（扭矩容量 `max_torque`）。差速器惯量计入输入端。
- **阻尼泄压钳制**：压缩速度被钳制到 ±2 m/s，属于调试期稳定化措施而非物理
  模型（真实减振器靠泄压阀实现类似行为）。高速坠地时着陆冲击弱于真实车辆。
- **质量适配**：默认参数面向约 1 吨级底盘。底盘质量过轻（如默认立方体）会使
  悬挂刚度与阻尼相对质量过大，表现为弹飞与翻滚；适配层应在初始化时校验质量
  并在日志中警告，悬挂参数按质量缩放。
- **子步上限**：每个求解器步内最多 32 个内部子步，帧率低于约 15 fps 且宿主未启用物理子步时，
  内部子步长会超过 2.5 ms，轮胎回路的数值稳定性随之退化。
- **离合器**：摩擦约束在扭矩上限 `engagement·max_torque·dt` 内锁止，超出则滑摩。
  离合器惯量计入输入端。
- **原生悬挂约束**：Chaos 的阻尼项以求解器步长为量纲（`D = SpringDamping·dt`），
  适配层按固定求解器步长换算；子步化或帧率变化时有效阻尼会漂移。
  轮胎摩擦圆的法向载荷仍取弹簧力 + 防倾杆模型估计，不是约束内部求解冲量。
- **物理状态重建**：原生悬挂约束在载具注册时绑定底盘物理对象；运行时重建底盘
  物理状态（切换碰撞、重设模拟）会使约束指向旧粒子，需要重新注册载具。
- **轮胎模型**为摩擦圆限制下的纵向冲量解与侧向刚度模型，含载荷敏感与滚动阻力；
  无瞬态松弛长度与胎体柔性。
- **发动机**：默认（`add_engine`）为线性衰减且关闭怠速/发动机制动；高级参数需使用
  `add_engine_with_params`。怠速为比例控制（无积分项），稳态误差由控制带宽决定。
- 空间域存在环时静默取树（BFS），未像信号域那样报错。

## 7. 构建接入

UE 侧（CirrovaEngine）链接本 crate 的 `staticlib` 产物：

```
cd ThirdParty/liminal
cargo build --release
# 产物：target/release/liminal[.lib|.a]
```

构建 UE 工程前须先执行上述命令；`CirrovaEngine.Build.cs` 已配置库路径。
