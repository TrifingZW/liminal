# 载具物理仿真路线研究报告

本文梳理载具物理仿真的主要技术路线，并以"一维动力流 + 空间域耦合"为轴比较它们的架构取舍。所述机制均来自各方案的公开文档、源码结构与社区技术资料；数字为量级描述，非精确值。

## 问题域：载具物理的结构

一辆载具在物理上是两类过程的耦合体：

- **空间域**：底盘作为六自由度刚体，在悬挂、轮胎与地面的作用下运动。涉及接触检测、约束求解、刚体积分。
- **旋转域**：一维旋转动力流。发动机、离合器、变速箱、传动轴、差速器、车轮构成一条扭矩与角速度双向传递的链路。

两域在**轮毂**处耦合：动力流输出的扭矩驱动车轮旋转；轮胎与地面的相互作用推动车身；地面的反作用以扭矩形式回流动力流。发动机支点处还存在第二耦合点（发动机扭矩的反作用作用于机体）。

所有技术路线都必须回答同一个架构问题：**这份耦合以什么语言书写、在物理引擎的什么位置发生**。对这个问题的不同回答，构成下文的四条路线。

## 轮地界面的功能分解

四条路线均作用于同一界面：车轮与地面。该界面可分解为三个职责不同的关注点：

- **接触检测**（查询）：以射线、形状投射、刚体碰撞或质点接触获得命中点、法线与距离；该环节不产生力，其结果仅作为悬挂与轮胎模型的输入。
- **悬挂**（法向通道）：描述车轮沿接触法线相对车身的运动，并计算法向支撑力。弹簧-阻尼、轴向约束、关节与结构构件均为其实现形态。
- **轮胎**（切向通道）：计算接触平面内的纵向力与侧向力。力模型、摩擦圆定界的约束、通用接触摩擦与结构涌现均为其实现形态。

**悬挂与轮胎的分界是接触法线，而非任何物理部件。** 法线方向归悬挂——支撑、载荷、行程；切平面（纵向、侧向）归轮胎——驱动、制动、侧偏。两个通道经载荷耦合：轮胎的切向力上限（摩擦圆）由悬挂提供的法向载荷定界，Jolt 中轮胎冲量界直接引用悬挂冲量（`GetSuspensionLambda`）。轮径与接触坐标系为共享量：轮径既参与悬挂的行程与轮心定位，又是扭矩与力的折算（M = F·r）；法线由接触检测给出，悬挂沿该法线作用，轮胎在其切平面内取纵向与侧向基。

以下三组术语在使用中常跨越上述分解的边界，需加以区分：

- **“射线悬挂”**：射线属于接触检测，弹簧-阻尼属于悬挂。该合称将查询与模型并入同一术语，易导致悬挂与射线检测的等同。
- **“轮胎”与“车轮”**：轮胎指切向力模型；车轮（轮速、转角、网格）为运动学量，是动力流经滑移率向轮胎域传递状态的耦合点。
- **“轮胎的垂直刚度”**：物理轮胎同时具有法向刚度与切向摩擦。路线一至三将这两个方向分别归入悬挂与轮胎通道；路线四中二者由同一结构产生，此即“边界消融”的含义。

按通道归纳四条路线：

| 路线          | 接触检测       | 悬挂（法向通道）        | 轮胎（切向通道）                  |
| ------------- | -------------- | ----------------------- | --------------------------------- |
| 外力施加者    | 悬挂射线       | 弹簧-阻尼力模型         | 滑移率/侧偏角力模型，摩擦圆裁剪   |
| 求解器内约束  | 射线或形状投射 | 轴向约束 + 行程限位     | 纵/侧向约束，冲量界由法向载荷定界 |
| 物理车轮      | 刚体碰撞       | 关节（滑动副/弹性约束） | 通用接触摩擦，无独立轮胎模型      |
| 质点-弹簧软体 | 质点接触       | 构件（结构的一部分）    | 质点摩擦 + 结构涌现，无通道划分   |

路线一至三中，该边界在代码与数据结构中显式存在，各通道具有可识别的独立实现；路线四中边界消融，法向刚度与切向摩擦均为同一质点-梁力学的输出，“悬挂”与“轮胎”仅指称结构的不同部位。

## 路线一：外力施加者

代表：ChaosVehicles（Chaos 物理引擎的载具方案）。

**机制**：

- 载具仿真系统作为物理引擎的客户端存在，引擎本身不感知"载具"概念。
- 悬挂不是约束：对每个车轮沿悬挂轴做射线检测，由命中距离得到当前弹簧长度，经弹簧-阻尼模型计算法向力。
- 轮胎是力模型：由滑移率、侧偏角与法向载荷计算纵向与侧向力，合力按摩擦圆裁剪。
- 一维动力流（发动机、变速箱、差速器）由载具系统自行显式积分；地面反作用扭矩作为外部注入回流。
- 力经引擎的延迟力通道注入刚体：仿真系统排队的力由引擎在物理子步内消费，而非渲染帧上直接施加。

**数值特性**：

- 轮胎力与轮速构成显式耦合回路：力由上一子步的轮速与车身速度快照计算，作用于下一子步。帧级步长下回路增益超过显式积分的稳定阈值，需要子步化压回稳定区。
- 静止与低速工况需要额外的稳定化处理，例如将阻力矩钳制到"本步内恰好停转"，以消除符号翻转类阻力在静止附近的震荡。
- 力的施加时序与求解器迭代不对齐：以状态快照计算出的恒力，近似整个子步内实际变化的相互作用。

**评价**：实现门槛最低——仅依赖物理引擎公开的力接口与射线查询，因此任何引擎都可以宿主。物理正确性受显式耦合与时序近似的限制；稳定化措施属于必要的补丁而非物理模型。

## 路线二：求解器内约束（冲量驱动）

代表：JoltPhysics 的载具方案。

**机制**：

- 载具向物理求解器注册为一组约束方程，成为求解过程的一等参与者。
- 求解前的准备阶段更新车辆状态：接触检测（射线或形状投射）、悬挂长度、接触坐标系。
- 速度迭代阶段，每个车轮贡献若干独立的标量约束方程——悬挂沿悬挂轴（含行程限位）、轮胎纵向、轮胎侧向——与场景中所有其它约束和接触在**同一迭代循环内以冲量求解、共同收敛**。
- 轮胎模型的角色发生变化：不再是力的公式，而是**约束的界**——摩擦圆限制轮胎约束可携带的冲量上限；"本步内轮面线速度对齐地面速度"的目标由车轮转动惯量与几何折算定义。
- 一维动力流仍是独立显式积分的系统，在轮毂处耦合：驱动力矩进入车轮旋转状态，轮胎约束产生的冲量以负载形式回流。

**数值特性**：

- 轮速与车身速度在同一迭代内隐式联立求解，轮胎回路天然稳定，不需要子步化或静止钳制类补丁。
- 与场景中其它约束（关节、接触）的相互作用在求解器内自然协调，因为它们共享同一个收敛过程。
- 轮毂处的动力流耦合仍是一步滞后——旋转域并未与空间域联立求解，但空间侧的隐式解消除了主导性的失稳来源。

**评价**：就射线式悬挂方案而言，数值条件与稳定性最好。代价是要求引擎开放求解器参与——载具必须作为求解器的扩展机制实现，跨引擎移植取决于各引擎是否暴露等价的能力。

## 路线三：物理车轮（关节化多刚体）

代表：无成熟的物理引擎级方案，见于独立作品与原型实验。

这条路线的本质是让车轮成为**刚体物质**——物理世界中的实体，而不是射线或形状查询的探针。就耦合语言而言，它与路线四同属物质耦合；两者的区别不在“有没有物质”，而在物质基元是刚体还是质点-梁。

**机制**：

- 车轮是真实的刚体，经关节连接到车身：锁定若干自由度，仅开放滚动轴。
- 悬挂是真实的关节（弹性约束或滑动副），行程与刚度由关节参数定义。
- 轮地摩擦由引擎的**接触求解器**产生——车轮刚体与地面碰撞，摩擦是接触解的一部分，而非任何轮胎模型的输出。
- 一维动力流可以完全消解：驱动力矩直接作用于车轮刚体，传动系以关节扭矩的形式存在，不需要独立的旋转域系统。

**特性**：

- 滚动、斜面行驶等行为直接来自物理引擎，无需载具专用代码。
- 天花板在于：通用接触求解器的摩擦不是轮胎模型。刚体的点或凸包接触没有接触斑概念，载荷敏感、纵侧向联合工况等轮胎行为无从表达；关节链在交互帧率下的稳定性依赖迭代预算。
- 语义上属于物质耦合的刚体版本，但把轮胎品质的上限交给了并不为此设计的通用机制。

**评价**：适合验证与原型，作为产品路线时通常需要回到前两条路线的轮胎模型，或走向以质点-梁为基元的软体物质路线。

## 路线四：质点-弹簧软体

代表：BeamNG、Rigs of Rods。

**基底**：它与路线三同属物质耦合——车轮、悬挂与车身都是物理世界中的实体，而不是探针；真正的分野在**物质基元**：路线三以刚体为基元，路线四以质点与弹簧-阻尼构件为基元。其余路线都构建于通用刚体物理引擎之上，载具是刚体物理世界的附加物或参与者；这条路线的引擎则是为质点-弹簧结构专门研发的独立软体物理引擎，刚体不是它的基元，也不存在“通用引擎 + 载具系统”的分层。

**血统**：两者均自研独立的软体物理引擎，一脉相承。Rigs of Rods 于 2005 年问世，搭载自研的梁结构物理引擎，后转为开源；2011 年其核心开发者组建 BeamNG，从零重写新一代专有节点-梁软体物理引擎。这条路线因此拥有两个可对照的参考实现，其中一个是开源的。

**机制**：

- **不存在载具子系统**。物理世界的基本元素是质点与连接质点的弹簧-阻尼构件（质点-弹簧系统）；“载具”只是对某种质点-构件排布的称呼。
- 一辆普通轿车由数百个质点与数千根构件组成骨架；物理引擎以约 2000 Hz 的固定频率解算所有质点的受力，以及构件的拉伸、压缩、弯曲与断裂。
- 车身是质点-构件网格；悬挂就是构件；轮胎是受内压作用的环形质点结构；摩擦作用于每个与地面接触的质点。
- 损伤即结构响应：构件受力超过阈值时发生塑性变形（静止长度被永久改写）或断裂（连接被移除）。车架扭曲、金属塑性形变、悬挂几何变化、传动轴断裂、轮胎形变全部是受力计算的自然结果，没有预设的损坏脚本。
- 唯一的独立子系统是一维动力流（发动机、变速箱、差速器），在轮毂旋转自由度与发动机支点处与结构耦合——与外力、约束路线中的旋转域在拓扑上同构。

**数值特性**：

- 刚性构件的稳定域要求千赫兹级固定步长（实际约 2000 Hz）；CPU 开销随质点数量增长，多线程并行是必需品。
- 载荷敏感摩擦、纵侧向联合工况、爆胎、形变、水滑全部涌现，无需模型。
- 世界必须自持：碰撞供给、宽相、材质系统、浮力都需要自己拥有，物理引擎无法更换；刚体密集的场景不是它的问题类。

**为何适用于真实载具仿真**：

- 工程级可信度：其商业姊妹版本被用于自动驾驶算法训练、传感器仿真（激光雷达、摄像头、雷达）与极限工况测试，保真度达到工程可用级。
- 品类扩展性：底层只有基础力学，同一套引擎通过改变质点质量分布与构件刚度、阻尼参数，即可覆盖家用轿车、重型卡车的车架柔性扭转、越野车非承载式车身形变、起重机吊臂承重，乃至飞机机翼的气动弹性形变——载具品类是参数问题，不是新代码问题。
- 基元与问题同构：车身、悬挂、轮胎与损伤共享同一套质点-梁力学；形变与拓扑变更不是外挂模型，而是基元本身的响应。这正是节点-梁软体引擎适合车辆与形变的原因。

**评价**：载具行为上限最高的路线，代价是拥有并维护整个物理世界，与通用游戏物理场景的需求不重合。传统刚体物理引擎中损伤依赖预设动画或网格顶点位移，而这里形变与损伤就是计算本身——这是它与其余路线在本体论层面的分歧。

## 对比：共同内核与耦合差异

四条路线中存在一个值得注意的收敛事实：除物理车轮路线可将动力流消解进关节外，**一维动力流作为独立求解域的地位在其余路线中不变**。外力路线与约束路线的传动系是独立显式积分的旋转系统；软体路线虽然把车身与轮胎彻底结构化，传动系仍是独立的旋转动力学系统。域分离不是某条路线的设计选择，而是问题本身的结构。

据此可以把四条路线放在同一条分解轴上：外力与约束共享完整的共同内核，差异只在耦合；物理车轮与物质路线则让出内核的模型部分，只保留动力流与信号。但“物理车轮”与“物质”并不是两个耦合层级——它们同属物质耦合，区别在世界基元。

- **共同内核**：信号编排 + 一维动力流求解 + 轮胎/悬挂力模型。
- **外力耦合**：内核的输出经力接口作用于刚体，反作用扭矩回流内核；内核完整保留。
- **约束耦合**：内核的输出转化为约束方程的参数（目标与冲量界），在求解器迭代内生效；内核完整保留。
- **刚体物质耦合（物理车轮）**：车轮成为刚体，悬挂成为关节，轮胎摩擦让位于通用接触求解；内核失去模型部分，只保留动力流与信号。
- **软体物质耦合（质点-弹簧）**：车轮、悬挂与车身由质点-梁结构涌现；内核同样只保留动力流与信号，空间域由专用软体世界承担。

### 物质耦合的内部区分

后两者同属物质耦合：车轮不再是射线或形状查询的探针，而是物理世界中的实体——有质量、参与碰撞与接触求解。这里的“物质”指物理引擎世界的基础组成部分（刚体、质点、构件等），不是渲染网格。因此，路线三与路线四不是“从物理车轮进入物质”的前后两级，而是同一级里的两种世界基元：

- 路线三：**刚体物质**。车轮、悬挂连杆与车身都是刚体，关节定义拓扑，接触求解器产生轮地摩擦；工程上仍有“载具装配”这一层。
- 路线四：**软体物质**。质点与弹簧-阻尼构件是基元，车身、悬挂、轮胎都是同一套结构的排布，接触作用于质点；不存在独立的“载具子系统”。

真正把路线四与前三者分开的，不是耦合深度，而是物理引擎的基元选择：前三者都可以寄生在通用刚体引擎上，路线四则要求世界本身以质点-梁为基元。节点-梁软体引擎之所以适合车辆与形变，不是因为它“更物质”，而是因为它的世界基元本身就是可变形结构——车身、悬挂、轮胎与损伤共享同一套力学，形变与拓扑变更无需外挂模型。

| 维度           | 外力施加者（ChaosVehicles） | 求解器内约束（JoltPhysics） | 物理车轮（刚体物质）    | 质点-弹簧软体（软体物质）  |
| -------------- | --------------------------- | --------------------------- | ----------------------- | -------------------------- |
| 物理基底       | 通用刚体物理引擎            | 通用刚体物理引擎            | 通用刚体物理引擎        | 专用节点-梁软体物理引擎    |
| 世界基元       | 刚体 + 探针                 | 刚体 + 探针                 | 刚体                    | 质点 + 梁（弹簧-阻尼构件） |
| 耦合语言       | 力                          | 冲量（约束方程）            | 物质（刚体/关节/接触）  | 物质（质点/梁/接触）       |
| 耦合位置       | 物理节拍边缘                | 求解器速度迭代内            | 世界之内（关节/接触）   | 世界之内（结构力学）       |
| 轮速与车身速度 | 显式交替，需子步化          | 隐式联立                    | 接触求解器联立          | 结构耦合，千赫兹积分       |
| 轮胎品质       | 模型上限（摩擦圆类）        | 模型定界的隐式解            | 通用接触摩擦            | 涌现                       |

| 一维动力流     | 独立域，轮毂耦合            | 独立域，轮毂耦合            | 可消解（融入关节）      | 独立域，轮毂耦合           |
| 对宿主的要求   | 公开的力接口与射线          | 求解器参与机制              | 刚体关节与接触求解器    | 质点-梁软体世界            |
| **可移植性**   | 最高                        | 依赖引擎暴露求解器          | 中等                    | 内核自带，宿主只剩渲染     |

两点引申：

1. **耦合深度改变的是数值卫生的位置，而不是共同内核**。外力路线下，稳定性负担（子步化、静止钳制、阻尼泄压）落在适配层；约束路线下，同样的负担被求解器的隐式解吸收。两种路线下共同内核的方程与接口可以保持一致，差异只在输出被解释为力还是约束参数。这为按宿主能力选择耦合深度提供了依据。
2. **约束路线与外力路线对共同内核的输出格式要求不同**。外力路线消费的是力（或折算冲量）；约束路线消费的是约束目标与冲量界。若同一套力模型要服务两者，需要同时具备两种输出形态。

## 取舍与结论

耦合深度构成一个谱系，但它的最后一步不是“从物理车轮进入物质”，而是“从刚体物质进入软体物质”：

**外力 → 约束 → 刚体物质 → 软体物质**

前两级共享“探针 + 模型”的内核，车轮不是物理实体；后两级共享“车轮是物理实体”这一事实，差别在世界基元。深度每进一级：

- 物理正确性与涌现行为的上限提高；
- 对宿主物理引擎的介入要求提高，可移植性下降，直至必须自有世界；
- 工程成本的重心从“模型与稳定化”转移到“求解器与世界基础设施”。

需要说明的是，谱系的前两级是同一刚体世界内的耦合深度递进；后两级则是物质耦合内部的世界基元更换——从通用刚体世界转向节点-梁软体世界。路线四之所以必须拥有整个世界，不是因为它“更物质”，而是因为它的世界基元（质点-梁）与通用刚体引擎的基元不兼容。节点-梁软体引擎之所以适合车辆与形变，也正是因为车身、悬挂、轮胎与损伤共享同一套可变形结构力学；形变与拓扑变更不是外挂模型，而是基元本身的响应。

没有全局最优的路线，只有与产品目标匹配的取舍：

- 追求广谱可移植与可控手感，外力路线是务实的选择；
- 追求物理正确与数值稳定，且宿主开放求解器参与，约束路线是当前工程实践中的优解；
- 追求车轮与环境的直接交互，并接受轮胎品质让位于通用接触时，物理车轮可作为原型或特定玩法的基础；作为产品路线，通常仍需回到前两条路线；
- 追求结构涌现的载具体验（形变、损伤、结构化轮胎），则需要自建软体世界，并接受其问题域与通用游戏物理场景的分离。

除物理车轮（刚体物质）路线可将动力流消解进关节外，无论走向哪条路线，一维动力流作为独立域、经轮毂与空间域双向耦合的结构不变。
